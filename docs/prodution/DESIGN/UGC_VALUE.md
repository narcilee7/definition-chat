# The UGC Value of Definition Chat

在这个产品里，UGC 不是"用户发帖子、写测评"，而是**用户铸造新的认知立场（Stance）并开放给他人调用**。

传统内容平台的 UGC 是**信息生产**，Stances 的 UGC 是**人格生产**。

---

## 这里的 UGC 到底是什么

**核心单元：一个 Stance 协议**

用户创建的不是一篇文章，而是一个**思想人格的声明式配置**：
- 核心认知习惯（怎么看问题）
- 语言调性（怎么说话）
- 禁忌（绝对不做的事）
- 响应模式（开场、沉默、撤退）

**举例**：
- 你创建了"尼采·权力意志" → 别人可以把自己的问题投给他看怎么分析
- 有人创建了"王阳明·心学" → 用户纠结"要不要辞职"时，让心学和斯多葛对位
- 甚至非哲学家："35岁被裁产品经理"、"抑郁症康复者"、" Buddhist Monk "

---

## UGC 的价值链

```
用户A（创作者）                 用户B（消费者）
   │                              │
   ▼                              ▼
 创建 Stance ──发布到市场──→ 浏览 / 搜索 / Fork
   │                              │
   ▼                              ▼
 获得反馈（被使用情况）      选择 Stance 进行折射/深潜/对位
   │                              │
   ▼                              ▼
 迭代 Stance 协议           在自己的分析中调用别人的 Stance
```

**关键**：创作者不生产"内容"，而是生产**被调用的认知接口**。

---

## 为什么这种 UGC 有网络效应

**1. 组合爆炸**
- 4 个内置 Stance 只能产生 C(4,2)=6 种对位组合
- 100 个 UGC Stance 能产生 4950 种对位组合
- 用户会发现意想不到的碰撞（"让王阳明和斯多葛辩论亲密关系"）

**2. 立场即身份**
- 创建一个 Stance 是在说"我是这样看世界的"
- 比发小红书更能表达深层认知结构
- 吸引同频者（和你之前"通过分享思考找同频者"的目标一致）

**3. 可验证性**
- 传统 UGC（文章、视频）的质量靠点赞数衡量
- Stance 的质量靠**调用次数**和**对话完成率**衡量
- 如果一个 Stance 被很多人选去深潜，说明它的认知协议有效

## 从 PGC 到 UGC 的演进

| 阶段 | 内容 | 说明 |
|---|---|---|
| **PGC 期** | 内置 4 个 Stance（罗素/荣格/斯多葛/老子） | 定义范式，教育用户什么是"认知协议" |
| **UGC 期** | 用户创建 + 平台审核/策展 | 爆发多样性，出现亚文化 Stance |
| **混合期** | PGC 标杆 + UGC 长尾 | 类似 Spotify 的官方歌单 + 用户歌单 |

**PGC 的标杆作用很重要**：
- 用户先理解"罗素是怎么被定义的"
- 才能创造出高质量的"加缪"或"自己的理想自我"

---

## UGC 的风险和边界

**1. 质量稀释**
- 用户可能创建"鸡汤大师"、"成功学导师"等劣质 Stance
- 解法：不算法推荐，靠**调用数据**自然排序；或者"策展人"机制

**2. 立场冲突与冒犯**
- 有人创建"宗教原教旨主义 Stance"
- 解法：Stance 必须声明**母体来源**和**认知习惯**，不能伪装成"客观真理"

**3. 情感依赖**
- 用户可能对某个 UGC Stance 产生依赖（比如"温柔姐姐"型）
- 解法：平台层面的**记忆隔离**和**无轮次限制但人格自厌倦**的设计，对所有 Stance 一视同仁

---

## 一句话总结

Stances 的 UGC 是**认知多样性市场**——用户不是生产内容供别人消费，而是生产**人格供别人借用、对话、对抗**。

你之前说"支持 Build 一个人格"，那个"Build"按钮就是 UGC 的入口。
